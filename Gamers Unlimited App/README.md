# Gamers Unlimited — App

The **Gamers Unlimited** launcher (a full rebrand — its own app, separate
from the old "The Dark Tides / Tides Downloader" build).

## Download
- **`Gamers Unlimited.exe`** — the launcher (Windows, single file, ~6.7 MB).
  No install needed: download and run.

## What it does
- Browse the game library and download games straight from Steam's CDN.
- Add downloaded games to Steam via an auto-written `.acf` appmanifest
  (Steam library is auto-detected from the registry + libraryfolders.vdf).
- "Add to Steam via SteamTools" option, Verify, pause/resume/cancel.
